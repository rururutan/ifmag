# Susie64 MAG plugin

This software is a Susie x64 plugin for MAG(まぐろーだー) format images.

## Thanks

The Susie I/F layer code was based on Masaru Miyasaka's Susie32 Pi Plug-in.
The MAG decoding specification was implemented with reference to MAGBIBLE and [M2BC](https://www.vector.co.jp/soft/win95/prog/se073910.html).
The MSX-specific features are based on the specifications described in MSXFLAG.DOC.
